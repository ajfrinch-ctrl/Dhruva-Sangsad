## ১. মোবাইল লেআউট স্পেক (সেকশন অনুযায়ী)

সাধারণ নিয়ম: এক কলাম · `page-head` (বিদ্যমান) · কার্ড `12px` · ইনপুট `10px`,
`min-height ≥ 44px` · প্রাইমারি অ্যাকশন = সবুজ block বাটন, ফর্মের শেষে অথবা
নিচে fixed action bar (`position: sticky; bottom: 0` + safe-area)।

### 1) সদস্য → নিবন্ধন (অগ্রাধিকার ১)

**মোবাইল (<1024px): ৩-ধাপ wizard** (সিদ্ধান্ত: wizard-ই; অ্যাকর্ডিয়ন
ব্যাকআপ অপশন হিসেবে রাখা — wizard-এ ভুল কম, প্রতি ধাপে 2–3 ফিল্ড)।

```
┌ page-head: সদস্য নিবন্ধন (i) ┐
│ ●━━○━━○  ধাপ ১/৩: যোগাযোগ    │  ← steps indicator (ট্যাপ নয়, শুধু অবস্থা)
├──────────────────────────────┤
│ [মোবাইল নম্বর *        ]     │  inputmode numeric, 11 digit
│  Member ID: 234567 (auto)    │  ← live hint, বিদ্যমান midHint রাখুন
│ [WhatsApp নম্বর *      ]     │  + ☑ মোবাইলের মতোই (বিদ্যমান sameWa)
│ [ইমেইল (ঐচ্ছিক)        ]     │
├──────────────────────────────┤
│ [← ফিরে যান] [পরের ধাপ →]    │  ← sticky bottom bar (safe-area)
└──────────────────────────────┘
ধাপ ২ — পরিচয়: নাম (বাংলা) * · নাম (ইংরেজি) * · পিতার নাম · মাতার নাম
ধাপ ৩ — কিস্তি ও ঠিকানা: মাসিক কিস্তি * · ঠিকানা · NID (ঐচ্ছিক) · পেশা · জন্মতারিখ
শেষ ধাপে বাটন: [সদস্য যোগ করুন ✓] (সবুজ, block)
```

- প্রতি ধাপে “পরের ধাপ” চাপলে শুধু ওই ধাপের validation (বিদ্যমান নিয়ম:
  মোবাইল/WhatsApp 11-digit, দুই নাম required, email/nid optional,
  installment > 0)।
- সাফল্য → বিদ্যমান success modal রাখুন, কিন্তু **বাংলা-প্রাইমারি** করুন
  (শিরোনাম “নিবন্ধন সফল”, Member ID · নাম · মোবাইল · `Pending Approval` ট্যাগ,
  ডিফল্ট পাসওয়ার্ড ব্যানার) + নিচে `banner('warn')`: “অনুমোদনের অপেক্ষায় —
  Maker/Admin অনুমোদন দিলে সদস্য সক্রিয় হবেন।”
- ডুপ্লিকেট মোবাইল/NID error → সংশ্লিষ্ট ধাপে ফিরিয়ে এনে field error
  (`registerMember` এর `fieldErrors` ম্যাপিং বিদ্যমান — রাখুন)।

### 2) সদস্য → সম্পাদনা (নাম বদল: “হালনাগাদ” → “সম্পাদনা”)

```

├──────────────────────────────────────┤

│ ┌ কমপ্যাক্ট ফর্ম (নিবন্ধনের ধাপ-ভাঙা   │
│ │  ছাড়াই, এক স্ক্রিন — সেকশন হেডার    │  যোগাযোগ · পরিচয় · কিস্তি
```

- Join Date (admin-only) + read-only Member ID/Status সারি রাখুন।

### 3) সদস্য → তালিকা (ডিফল্ট ট্যাব)

Hub-এর ডিফল্ট `register` → **`search`** করুন (FAB “সদস্য যোগ” register-এ
নিয়ে যায় — ওটা থাকছে, তাই দৈনন্দিন কাজ = খোঁজা দিয়েই শুরু)।

```
┌ [🔍 ID / নাম / মোবাইল …………] ┐  ← search-box (বিদ্যমান), autofocus নয়
│ (চিপ) [সব] [সক্রিয়] [অপেক্ষমাণ] [বাতিল] │ ← chip-btn (approval inbox থেকে)
│ (চিপ) [শুধু বকেয়া] [শুধু অগ্রিম]         │
│ ১২ জন সদস্য · মোট বকেয়া ৳৮,৫০০          │ ← count-line
├──────────────────────────────────────────┤
│ ┌ কার্ড ─────────────────────────────┐ │
│ │ রহিম উদ্দিন  [সক্রিয়]              │ │  লাইন ১: নাম + statusTag
│ │ 234567 · 01712-345678              │ │  লাইন ২: ID · মোবাইল
│ │ কিস্তি ৳৫০০ · জমা ৳১২,০০০ ·        │ │  লাইন ৩: কিস্তি · জমা ·
│ │ বকেয়া ৳১,০০০ · অগ্রিম ৳০           │ │  বকেয়া (লাল, >0 হলে) · অগ্রিম
│ │ [👁 দেখুন] [✎ সম্পাদনা] [🟢WhatsApp]│ │  ছোট বাটন + বাংলা লেবেল
│ └───────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

- “View / Edit / WA / ACTION / MOBILE / STATUS” EN টেক্সট → দেখুন / সম্পাদনা /
  WhatsApp; হেডার টেক্সট কার্ডে দেখা যায় না (ডেস্কটপ টেবিলে বাংলা হেডার §৪)।
- কার্ড ট্যাপ = দেখুন (পুরো কার্ড `<button>` নয় — ভিতরে বাটন থাকে বলে;
  শুধু হেডার অংশ ট্যাপে `viewMember`)।
- Empty: `emptyState({ ic:'search', title:'কোনো সদস্য পাওয়া যায়নি',
  actionLabel:'সদস্য যোগ করুন', onAction: register ট্যাবে যান })`।

## ৪. ডেস্কটপ (≥1024px) — কী আলাদা

- **শেল**: Icon Rail (বিদ্যমান) · bottom nav লুকানো · FAB → ডান-নিচেই থাকে
  (বিদ্যমান; রেইল-ডকে সরানো optional, এখন নয়)।
- **তালিকা**: একই ডেটা → `tableWrap` টেবিল (বিদ্যমান হেডারগুলো §৩-এর বাংলা
  করুন); মোবাইল কার্ড `<768px`-এ (বিদ্যমান card-table breakpoint-এর সাথে
  সামঞ্জস্য — JS-এ `matchMedia('(max-width:767px)')` দিয়ে রেন্ডার বেছে নিন)।
- **ফর্ম**: wizard → এক পেজে 2-কলাম (`g2`) কমপ্যাক্ট ফর্ম (একই `field()`
  পার্টস, একই validation); memberPicker → picker-ই (বড় select ফিরিয়ে নয় —
  হাজার সদস্যেও স্কেল করে)।
- **শিট**: `bottomSheet` ≥640px-এ centered modal হয় (বিদ্যমান) — filter sheet
  ও “আরও” ডায়ালগ হিসেবে দেখাবে; desktop rail-এ “আরও” আইটেমও থাকে (বিদ্যমান)।
- **রিপোর্ট**: টাইপ গ্রিড 4-কলাম; ফলাফল টেবিল + ডান-উপরে export icon-bar
  (sticky নয়)।
- **টাচ টার্গেট**: ডেস্কটপে 36–40px dense থাকতে পারে; 44px নিয়ম মূলত
  `<1024px` (বিদ্যমান `.btn` স্কেল রাখুন)।

### (ক) গ্লোবাল রঙ / FAB / “আরও”-আইকন / কুইক-টোন [S]

- `js/icons.js`: `menu` (hamburger) আইকন যোগ; `js/app.js`: `moreButton()` +
