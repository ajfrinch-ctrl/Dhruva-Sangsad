# ধ্রুব সংসদ — Mobile-first UI/UX ডিজাইন সিস্টেম

> লক্ষ্য: একটি আধুনিক fintech/banking অ্যাপের মতো অভিজ্ঞতা — কম ট্যাপ, আইকন-নির্ভর নেভিগেশন,
> কার্ড-ভিত্তিক লেআউট, এবং মোবাইল-প্রথম (Desktop-এ মানানসই)।
>
> ভিত্তি: বিদ্যমান কোড (`index.html`, `css/app.css`, `js/app.js`, `js/icons.js`)।
> এই ডকুমেন্টটি ডিজাইন স্পেসিফিকেশন; পরে ধাপে ধাপে কোডে রূপান্তর করার রোডম্যাপ শেষে দেওয়া আছে।

## ০. এক নজরে সিদ্ধান্ত

| বিষয় | সিদ্ধান্ত |
|---|---|
| নেভিগেশন (মোবাইল) | নিচে Fixed Bottom Nav — ৫টি আইকন (হোম · সদস্য · জমা · অনুমোদন · আরও) |

### ১.৩ স্পেসিং · রেডিয়াস · টাইপোগ্রাফি

```
Spacing scale (4pt):  4  8  12  16  20  24  32  40
Radius:  card 12px · button/input 10px · chip/tag 999px · sheet 20px 20px 0 0
Shadow:  0 1px 2px rgba(16,24,40,.05), 0 1px 3px rgba(16,24,40,.06)   (dark-এ shadow → border)
```

| স্টাইল | সাইজ / লাইন-হাইট | ব্যবহার |
|---|---|---|
| Display | 28px / 1.25 | Hero টাকার অঙ্ক |
| H1 (পেজ) | 20px / 1.3 | স্ক্রিন টাইটেল |
| H2 (সেকশন) | 15px / 1.35 | কার্ড হেডার |
| Body | 14px / **1.65** | সাধারণ টেক্সট (বাংলার জন্য 1.6+ জরুরি) |
| Label | 12px / 1.4 | ফিল্ড লেবেল, কার্ড সাব-টেক্সট |
| Caption | 11px / 1.4 | টাইমস্ট্যাম্প, মেটা |
| Numerals | `font-variant-numeric: tabular-nums` | সব টাকার ঘর |

**বাংলা টাইপোগ্রাফি নীতি**: `line-height ≥ 1.6`; শিরোনামে `letter-spacing: 0` (মাত্রা আটকাবে না);
সংখ্যা/তারিখের জন্য `tabular-nums`; ট্রান্সলিটারেটেড ইংরেজি শব্দের আগে/পরে স্পেস;
লম্বা নাম `text-overflow: ellipsis` (কিন্তু স্ট্যাটাস বা টাকার অঙ্ক কখনো কেটে ফেলবেন না)।

### ১.৪ টাচ টার্গেট ও ইন্টারঅ্যাকশন

- সব ট্যাপেবল এলাকা **≥44px**, প্রাথমিক বাটন **48px**, FAB **56px**
- বটম নেভ আইটেম: 48px উচ্চতা · আইকন 24px · লেবেল 10.5px
- সেফ এরিয়া: `padding-bottom: env(safe-area-inset-bottom)` বটম নেভ/শিটে
- প্রেস ফিডব্যাক: `transform: scale(.97)` + 120ms · হ্যাপটিকস নেই (ওয়েব), তাই রঙ-পরিবর্তন দিয়ে ফিডব্যাক

## ৩. নেভিগেশন সিস্টেম (সবচেয়ে গুরুত্বপূর্ণ)

### ৩.১ বটম নেভিগেশন — স্পেসিফিকেশন

```
┌──────────────────────────────────────────────┐
│  ●           স্ক্রিন কনটেন্ট (scroll)         │
│         (FAB ডানে-নিচে, নেভ-এর উপরে)          │
├──────────────────────────────────────────────┤ ← 1px border + subtle shadow (upward)
│  🏠     👥      💰      ✅      ☰            │   height 56 + safe-area
│  হোম   সদস্য   জমা   অনুমোদন  আরও           │   icon 24 · label 10.5
│  ───                                          │   active: 2px pill indicator
└──────────────────────────────────────────────┘
```

- **উচ্চতা**: 56px + `env(safe-area-inset-bottom)`; কনটেন্টে `padding-bottom: 84px`
- **অ্যাক্টিভ স্টেট**: আইকন + লেবেল `var(--green-600)`, উপরে 2px গোল ইনডিকেটর (`#16a34a`)
- **ইনঅ্যাক্টিভ**: `--faint`
- **ব্যাজ**: অনুমোদনে লাল ডট/পিল (`#e11d48`, সর্বোচ্চ 99+) — পেন্ডিং সংখ্যা
- **আচরণ**: স্ক্রল ডাউনে টপবার collapse (হাইট 56→0), স্ক্রল আপে ফিরে আসে; বটম নেভ সবসময় দৃশ্যমান
- **ট্যাপ**: ট্যাপ করা ট্যাব আগেই অ্যাক্টিভ থাকলে → সেই স্ক্রিনের শীর্ষে স্ক্রল + রিফ্রেশ
- **রুট বদল**: `history.pushState` নয় — বিদ্যমান `location.hash` রাউটারই ব্যবহার করুন

### ৩.২ FAB (প্রাথমিক অ্যাকশন)

| স্ক্রিন | FAB | রোল |
|---|---|---|
| সদস্য | `+` সদস্য যোগ | Admin / Maker |
| জমা | `+` জমা যোগ | সব |
| অনুমোদন | ✕ (FAB নেই — বাল্ক অ্যাকশন বার) | Admin / Maker |
| হোম | ✕ (Quick Actions যথেষ্ট) | — |

- আকার 56×56, `bottom: 72px; right: 16px`, `box-shadow: 0 6px 18px rgba(22,163,74,.35)`
- লম্বা তালিকায় স্ক্রল-ডাউনে FAB shrink → শুধু আইকন; স্ক্রল-আপে লেবেলসহ ফিরে আসে

### ৩.৩ “আরও” শিট (Bottom Sheet)

```
╭──────────────────────────────────────╮   ← drag handle
│  রিপোর্ট          📊                  │
│  সেটিংস           ⚙️                  │
│  ইউজার ম্যানেজমেন্ট 👥                │
│  ব্যাকআপ          💾                  │
│  অ্যাকটিভিটি লগ    🗒️                  │
│  ─────────────────────────────────   │
│  🌙 ডার্ক মোড            [ toggle ]  │
│  🌐 ভাষা  বাংলা | EN     [ toggle ]  │
│  ─────────────────────────────────   │
│  লগআউট            ⏻ (লাল)            │
╰──────────────────────────────────────╯
```

- ব্যাকড্রপ ট্যাপ / নিচে সোয়াইপ → বন্ধ; প্রতিটি সারি 48px, আইকন 22px
- লগআউট সবসময় নিচে, লাল টেক্সট, কনফার্ম ডায়লগ

### ৩.৪ ডেস্কটপ: Icon Rail (≥1024px)

```
┌────┬───────────────────────────────────────────────┐
```

## ৮. ডেস্কটপ অ্যাড্যাপ্টেশন (নীতি)

| ব্রেকপয়েন্ট | লেআউট |
|---|---|
| `< 640px` | বটম নেভ · 1-কলাম · কার্ড লিস্ট · ফুল-স্ক্রিন শিট · FAB |
| `640–1023px` (ট্যাবলেট) | বটম নেভ · 2-কলাম গ্রিড · কার্ড লিস্ট (প্রশস্ত) · FAB |
| `≥ 1024px` | বামে Icon Rail (72/240px) · কনটেন্ট max 1200px · টেবিল ভিউ · FAB → টপ-রাইট বাটন |

- **বটম নেভ → রেইল**: একই `NAV` কনফিগারেশন থেকে রেন্ডার (ডুপ্লিকেট মার্কআপ নয়)
- **কার্ড → টেবিল**: একই ডেটা, CSS দিয়ে ভিউ সুইচ (`list-view` / `table-view`) — JS দুইবার রেন্ডার নয়
- **শিট → ডায়লগ**: 640px-এর উপরে বটম শিট → সেন্টারড মোডাল
- **ড্যাশবোর্ড**: ডেস্কটপে 2-কলাম (বামে 8fr: হিরো + লিস্ট · ডানে 4fr: স্ট্যাট + পেন্ডিং)
- **কীবোর্ড**: `g h/m/d/a` দিয়ে স্ক্রিন · `/` সার্চ · `Esc` বন্ধ · `?` শর্টকাট হেল্প
- **ঘনত্ব**: ডেস্কটপে সারি উচ্চতা 44→36px, ফন্ট 14px অপরিবর্তিত

## ৯. মোশন · অ্যাক্সেসিবিলিটি · পারফরম্যান্স

- **মোশন**: 120–200ms, `cubic-bezier(.2,.8,.2,1)`; স্ক্রিন ট্রানজিশন = ফেইড + 8px উল্লম্ব স্লাইড;
  শিট = নিচ থেকে 240ms; `prefers-reduced-motion`-এ সব ট্রানজিশন বন্ধ
- **অ্যাক্সেসিবিলিটি**: কনট্রাস্ট ≥ 4.5:1 (ডার্কে primary `#22c55e`), ফোকাস রিং 2px `--green-600`,
  প্রতিটি আইকনে `aria-label`, বটম নেভে `role="tablist"`, স্ট্যাটাস শুধু রঙ নয় (টেক্সট/আইকনও)
- **পারফরম্যান্স**: ইনলাইন SVG স্প্রাইট (বিদ্যমান `icons.js` মতো), সিস্টেম ফন্ট ফলব্যাক,
  `content-visibility: auto` লম্বা লিস্টে, ছবি lazy, শিট/মোডাল lazy-render
- **PWA**: `display: standalone`, সেফ-এরিয়া, স্প্ল্যাশ, শর্টকাট (`জমা যোগ`)

### ১০.১ ধাপ ৮-এর পালিশ (সব সম্পন্ন ✅)

- **সোয়াইপ অ্যাকশন** — অনুমোদন সারিতে ডানে সোয়াইপ = অনুমোদন, বামে = বাতিল
  (`attachSwipe()`; বাটনের মতোই confirm ডায়ালগ আসে, তাই ভুলে কিছু হয় না)
- **পুল-টু-রিফ্রেশ** — `.main`-এর একদম উপর থেকে নিচে টানলে রিফ্রেশ
  (threshold 56px, `overscroll-behavior: contain` দিয়ে নেটিভ PTR বন্ধ রাখা)
- **হ্যাপটিক-ফিল** — `navigator.vibrate()`; success/error টোস্টে ও সোয়াইপ/PTR
  threshold পার হলে (`haptic()`; iOS-এ বা reduced-motion-এ নীরব no-op)
- **টপবার collapse-on-scroll** — মোবাইল শেলে নিচে স্ক্রল করলে টপবার লুকিয়ে
  জায়গা বাড়ে, উপরে স্ক্রল করলেই ফিরে আসে (`body.tb-hidden`)

প্রস্তাবিত অগ্রাধিকার অনুযায়ী **১ → ৮** ধাপের সবগুলো কোডে রূপান্তরিত হয়েছে ✅
